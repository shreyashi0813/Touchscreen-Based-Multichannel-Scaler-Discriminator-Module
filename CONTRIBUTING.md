# Contributing

Before contributing, please ensure that submitted code and design files can legally and appropriately be shared publicly.

- Include board model and tool/library versions when reporting build issues.
- Keep secrets, credentials, personal information, and private institutional material out of commits.
- Validate pin mappings and circuit values against the actual hardware before proposing changes.
- Use focused pull requests and describe how they were tested.

This repository is not an official publication of BARC.
